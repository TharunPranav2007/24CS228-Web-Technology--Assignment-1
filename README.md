## 5️⃣ Supermarket Billing System

### Scenario

A supermarket wants to generate customer bills automatically.

### Implementation

A JavaScript-based **Supermarket Billing System** that accepts quantity and unit price for three products and calculates the final payable amount.

### Features

- Customer Name
- Bill Number
- Three Product Entries
- Quantity Input
- Unit Price Input
- Live Product Amount Calculation
- Total Bill Calculation
- 10% Discount Calculation
- Final Payable Amount
- Bill Summary
- Reset Function
- Input Validation

### Billing Logic

```text
Product Amount = Quantity × Unit Price

Subtotal = Sum of all Product Amounts

If Subtotal > ₹2000:

    Discount = 10% of Subtotal

Otherwise:

    Discount = ₹0

Final Payable Amount = Subtotal - Discount
```

### JavaScript Concepts

- Variables
- Data Types
- Literals
- Arithmetic Operators
- Comparison Operators
- Conditional Statements
- Iteration
- User-defined Functions
- DOM Manipulation
- Event Handling

### Technologies Used

- HTML5

# ▶️ How to Run the Projects

## Method 1 – Direct Browser

1. Clone the repository.

```bash
git clone <repository-url>
```

2. Open the repository in VS Code.

3. Navigate to the required scenario folder.

4. Open the `index.html` file in a web browser.

---

## Method 2 – VS Code Live Server

1. Install the **Live Server** extension in VS Code.
2. Open the required scenario folder.
3. Right-click `index.html`.
4. Select **Open with Live Server**.
5. The webpage will open in the browser.
