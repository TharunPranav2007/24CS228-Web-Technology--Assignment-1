Welcome to the World Wide Web

The World Wide Web is a system of interconnected web pages and resources that can be accessed through the Internet using web browsers.

This page explains the fundamental concepts required to understand how websites communicate and operate.

01

Internet Overview

The global network connecting computers and devices.

The Internet is a worldwide network of interconnected computer networks. It allows computers, mobile devices, servers and other devices to communicate and exchange information.

When a user accesses a website, the device communicates with a web server through the Internet to request and receive information.

02

Fundamental Computer Network Concepts

Understanding how devices communicate with each other.

🏠

LAN

Local Area Network connects devices within a limited geographical area such as a home, laboratory or college building.

🏙️

MAN

Metropolitan Area Network connects networks across a city or large campus.

🌍

WAN

Wide Area Network covers a large geographical area. The Internet is the largest example.

🔗

Protocol

A protocol is a set of rules that defines how devices communicate and exchange data.

03

URL and Its Structure

Understanding the address used to access web resources.

URL stands for Uniform Resource Locator. It specifies the location of a resource on the Web.

https://www.example.com/about/index.html
https://

Protocol used to communicate securely.

www

Indicates the web service or host.

example.com

Domain name of the website.

/about/index.html

Path identifying the requested resource.

Domain Name

The human-readable identity of a website.

A domain name is a human-readable name used to identify a website on the Internet. It is easier for users to remember than a numerical IP address.

05

Web Browsers and Web Servers

Two important components of the Web.

🌐

Web Browser

A web browser is software used to access and display websites. It interprets HTML, CSS and JavaScript and presents the result to the user.

  • Requests web resources
  • Displays web pages
  • Executes client-side JavaScript
🖥️

Web Server

A web server is a system that stores and delivers web resources to clients when they request them.

  • Receives client requests
  • Processes requests
  • Sends responses to clients
